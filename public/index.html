WHY I BUILT THIS

I wanted one setup that just worked.

I started building Discord bots because the ones my server relied on were never quite right. One played music well and handled moderation badly. Another had a hundred commands and no clear dashboard.

I kept stitching them together, and every fix broke something else. So I stopped patching and started building: one bot for each job, each tuned until it works, all controlled from one dashboard.

Aurex is the setup I always wanted for my own community. If it helps yours run better, it did its job.

— Lucifer, founder of Aurex

AUREX VS ALL-IN-ONE BOTS

One bot for each job, not one bot for everything.

Installing only what you need means fewer things can break.

Aurex
